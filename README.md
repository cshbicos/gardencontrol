# GardenControl

An Arduino based controller project for my garden automations

There are two versions of this project:

1. An initial WIFI based version with a ESP/UNO based board (the older version of this project)
2. An ethernet shield based version with a simple UNO board (the newer version of this project)

Both versions connect a relay to control Solenoid valves (or whatever you like), the shield version also handles a moisture sensor.

See the README.md in the individual subfolders for further details.
